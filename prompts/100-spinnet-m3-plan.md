## 1. Method (equations; sources and details in `docs/METHODS-spinnet.md`)

**1.1 Encoding (codec).** Data register `d[0..7]`: qubits 0–3 = inner links $b,r,t,l$ (bit $=1\iff j=\tfrac12$), qubits 4–7 = corner qubits $c_0..c_3$ (bit $=1\iff J_c=1$; $J_c\in\{0,\tfrac12\}\to0$). Outer register `o[0..7]`: outer link $o_k$ (METHODS §1 order) at qubit $8+k$. Code of a label: $\mathrm{code}=\sum_{l<4}[j_l{=}\tfrac12]2^l+\sum_c[J_c{=}1]2^{4+c}+\sum_k[j_{o_k}{=}\tfrac12]2^{8+k}$. Every corner has $J_c=1$ only when its four links are $\tfrac12$ (fusion rule $T(\tfrac12,\tfrac12)=\{0,1\}$ on both sides), so the corner-qubit rule of the decision holds by construction, the map label→code is injective (the admissible $J$'s of a corner never contain both $0$ and $\tfrac12$: `corner_jbit_injective`), the 433 physical states are 433 distinct unit codes, and the valid data codes are the **47 inner labels** $((j_b,j_r,j_t,j_l),(J_0..J_3))$ (16 with no corner bit = bright, 31 dark). Register names as the M1 pattern (`d`, `o`, then ancillas), so the laptop's evaluator (`_phys_data`, `layout_of` through registers) and metrics work unchanged; `is_basis_encoding = True`.

**1.2 Target = route B, gauge to route A.** $H_B^{\rm B}=-(\mathcal P+\mathcal P^{\mathsf T})$ from the 6j product (METHODS §5, `exact.spinnet.h_magnetic_phys_6j`), $H_E=\sum_{\ell\,{\rm inner}}j_\ell(j_\ell+1)$ diagonal; $U_B(\beta)=e^{-i\beta H_B^{\rm B}}$, $U_E(\alpha)=e^{-i\alpha H_E}$, steps as METHODS §2, all in route-B label order (identical to `PhysicalBasis.labels`, asserted). Route A relates by the real diagonal gauge $D=\pm1$ of `gauge_align(H_A,H_B^{\rm B})` (residual $2.7\cdot10^{-15}$, 64 minus signs): $H_A=DH_BD^\dagger\Rightarrow V_B=D^\dagger V_AD$ ($2.4\cdot10^{-15}$). The decoded electric vector of code $k$ is $\phi_k=D_k\psi^A_k$, so $\langle\phi_{k'}|H|\phi_k\rangle=(H_B)_{k'k}$ exactly and the Gauss check of decoded outputs is consistent with the target. Block structure (M0-X5): the physical target restricted to any outer pattern is the $47\times47$ inner operator $e^{-i\beta K}$ with $K=K_{\rm inner}$; measured couplings on the inner codes: $K=-2$ (vacuum pair 0000↔1111), $-\tfrac12$ (alternating pair 0101↔1010), $+1$ (six pairs), 31 dark rows; partner $=\mathrm{code}\oplus0b1111$, corner bits unchanged.

**1.3 Sign of $\beta$ is a gauge here (physics finding, asserted by M3-K1).** $K$ is a matching, so $D'KD'=-K$ for $D'=-1$ on one member of each pair; hence $U_B(-\beta)=D'U_B(\beta)D'$ in the code basis and $H_E\pm H_B$ are isospectral at $j_{\max}=\tfrac12$. Consequences: (i) external circuits are compared **up to a real diagonal gauge of the code basis** found from the circuit's own 47×47 block (`align_inner_block`; the gauge is recorded, one $-1$ per bright pair expected); (ii) "$-\beta$ rejected" in M3-S1 only pins our circuit to the route-B sign gauge of the target (not a physics check; in M1 it was one).

**1.4 Decoding of invalid-but-in-code-space outputs (span leak).** The evaluator decodes outputs on valid inner codes × any outer pattern (`decode_state`); 11 599 of the $47\cdot256$ combinations are inadmissible labels (a corner whose pairs cannot fuse to a common $J$, or a corner bit set where $J=1$ is not admissible). They are decoded to the product state with every spin-$\tfrac12$ end at corner $c$ at $m=+\tfrac12$ (corner bit 0) or $-\tfrac12$ (corner bit 1), far ends $+\tfrac12$: an isometry on the whole code space (orthogonal to all physical states and mutually orthogonal: an inadmissible corner always has $\ge1$ spin-$\tfrac12$ end, hence $M\neq0$), with Gauss residual $\ge\tfrac12$ (analytic: $\|G^z_c\phi\|=k/2$ for $k\ge1$ aligned ends; measured minimum over all 11 599 codes exactly $0.5$). So the prompts/004 span-leak bound $\|s\|\le4\cdot$`gauss_residual` keeps its hypothesis (every decoded code-space vector outside $\mathcal P$ has $\sum_{c,a}\|G^a_cs\|^2\ge\tfrac34\|s\|^2$) and a wrong circuit is caught at first order.

**1.5 General circuit `build_UB` = frame + flags + 4-rotation phase walk (angles solved from $K$).** With $H$ conjugation, $U_B$ on a bright pair with coupling $k$ is $e^{-i\beta kX}\to e^{-i\beta kZ_0}=R_z(2\beta k)$ on the frame target; dark slots need $R_z(0)$.
- Frame `cx(1,3); cx(0,1); cx(0,2)` (control, target on data wires): afterwards $q_0=j_b$ (flip target), $q_1=m_1=j_b\oplus j_r$, $q_2=m_2=j_b\oplus j_t$, $q_3=m_3=j_r\oplus j_l$ (all invariant under the four-link flip; `frame_maps_flip`). Classes: vacuum pair $m=000$, alternating pair $m=100$, the six others.
- `h(q0)`; flags into clean ancillas `a[0..6]` $=(A,B,F,P,Q,G_1,G_2)$ by relative-phase Toffolis: `x` on $c_0..c_3$; `rccx(c0,c1→A)`, `rccx(c2,c3→B)`, `rccx(A,B→F)` ($F=$ all corner bits 0 = bright flag); `x(q2); x(q3); rccx(q2,q3→P)` ($P=[m_2{=}m_3{=}0]$); `rccx(F,P→Q)`; `x(q1); rccx(Q,q1→G1); x(q1)` ($G_1=F\wedge[m{=}000]$, vacuum pair); `rccx(Q,q1→G2)` ($G_2=F\wedge[m{=}100]$, alternating pair).
- Walk on $q_0$: `rz(θ0); cx(F,q0) rz(θF) cx(F,q0); cx(G1,q0) rz(θ1) cx(G1,q0); cx(G2,q0) rz(θ2) cx(G2,q0)`, i.e. $\theta(y)=\theta_0+\theta_F\chi_F+\theta_1\chi_{G_1}+\theta_2\chi_{G_2}$ with $\chi=(-1)^{\rm flag}$ (Walsh series, Welch–Greenbaum–Mostame–Aspuru-Guzik, New J. Phys. 16, 033040 (2014), arXiv:1306.3991, Sec. 2); solved exactly from $\theta(y)=2\beta k(y)$ on the valid slots: $(\theta_0,\theta_F,\theta_1,\theta_2)=(-\tfrac72,-1,3,\tfrac32)\beta$ (least-squares residual $4\cdot10^{-15}$; check: dark $0$, others $+2\beta$, vacuum $-4\beta$, alternating $-\beta$).
- Uncompute = the flag sequence reversed (`rccx` is Hermitian and self-inverse; the segment between compute and uncompute is diagonal, so the relative phases cancel: METHODS §11.1 sandwich lemma `Su2Plaq.sandwich`; Maslov, PRA 93, 022311 (2016), arXiv:1508.03273); `h(q0)`; frame reversed.
Measured: 54 CX, 4 rotations (angles linear in $\beta$, denominators $\le2$ ⇒ Lean-certifiable), $T_{\rm fixed}=56$, depth 67, 7 ancillas (15 qubits + 8 outer); exact to $1.0$–$1.4\cdot10^{-14}$ at $\beta\in\{0.23,0.61,1.0\}$, both step orders $1.2\cdot10^{-14}$; $-\beta$ target rejected (error 1.88). $T(\varepsilon)$ for $U_B$: 230/310/396/468 at $\varepsilon=10^{-4..-10}$; step order 1: 406/566/724/884.
