## 1. Method (equations, conventions, sources; details in `docs/METHODS-rishon.md` R9)

**Conventions (unchanged from R2/R8).** Link $\ell$ on qubits $(4\ell,4\ell+1,4\ell+2,4\ell+3)=(L_1,L_2,R_1,R_2)$, little-endian, bit $k$ of the basis index = occupation of mode $k$; `JW.lean`: $c_k=(\prod_{m<k}Z_m)\sigma^-_k$, `mode false n k` $=c_k$, `mode true n k` $=c_k^\dagger$, `comp A B` = apply $B$ first; `sector = [3, 5, 6, 9, 10, 12]`, `linkA = [3]`, `linkB = [12]`, `linkQ = [5, 6, 9, 10]`; `Uop i j = comp (mode false 4 i) (mode true 4 (2 + j))` $=c_{L,i}c^\dagger_{R,j}$.

**W1 — certificate link matrices (P1) and link algebra (P2).**
- `Udop i j := comp (mode false 4 (2 + j)) (mode true 4 i)` $=c_{R,j}c^\dagger_{L,i}=U_{ij}^\dagger$.
- `sectorEntries A` = the list of $(\text{row},\text{col},v)$ with row/col = positions in `sector` of $t$ and $s$ for every $(t,v)\in A\,s$, $s\in$ `sector`; `sameSet a b` = equal lengths and mutual containment. `linkOpsData := rishonHBCert.linkOps` (imported from `Su2PlaqCert.Rishon.HBData`; order `U00,U01,U10,U11,Ud00,Ud01,Ud10,Ud11`, HB.lean header).
- Theorem `hb_link_ops_from_jw`: $\forall i,j<2$: `sameSet (linkOpsData[2i+j]) (sectorEntries (Uop i j))` ∧ `sameSet (linkOpsData[4+2i+j]) (sectorEntries (Udop i j))` ∧ `sameSet (linkOpsData[4+2i+j]) (map (r,c,v) ↦ (c,r,v) linkOpsData[2i+j])` ∧ both operators keep the sector; `hb_link_ops_count : linkOpsData.length = 8`.
- Theorem `det_u_identity : OpEq 4 (add (comp (Uop 0 0) (Uop 1 1)) (smul (-1) (comp (Uop 0 1) (Uop 1 0)))) detU` — $\det U=U_{11}U_{22}-U_{12}U_{21}=2U_{11}U_{22}$ as an operator identity on all 16 states (derivation: $U_{12}U_{21}=-U_{11}U_{22}$ by three anticommutations; BCW arXiv:hep-th/9704106 Eq. 4.6). Theorem `u_commute : ∀ i j k l < 2, OpEq 4 (comp (Uop i j) (Uop k l)) (comp (Uop k l) (Uop i j))`.

**W2 — corner Gauss kernel (P3).** Corner with ends $e=0..3$ on qubits $(2e,2e+1)$ = (colour 1, colour 2) (as `end_generator`, bit 0 = colour 1). End configuration $m=\sum_em_e3^e$, $m_e\in\{0\!:\!\text{empty }00,\ 1\!:\!\text{full }11,\ 2\!:\!\text{one rishon }01|10\}$; `cornerBasis m` = the 8-bit states allowed by $m$ ($D=2^{\#\{e:m_e=2\}}\le16$). Generators on 8 modes from `JW.lean`:
$$2G^z=\sum_e(n_{e,1}-n_{e,2}),\qquad G^+=\sum_ec^\dagger_{e,1}c_{e,2},\qquad G^-=\sum_ec^\dagger_{e,2}c_{e,1},$$
($T_a=\sigma_a/2$, colour 1 = up; $G^x=\tfrac12(G^++G^-)$, $G^y=\tfrac1{2i}(G^+-G^-)$, so the joint kernel of $G^z,G^\pm$ is the SU(2)-singlet space). `matrixOf A basis` = integer matrix $\langle t|A|s\rangle$; `rank` = number of pivots of fraction-free elimination ($r_j\leftarrow p\,r_j-a_{jc}r_{\rm piv}$, no division; Bareiss, Math. Comp. 22 (1968) 565–578, DOI 10.1090/S0025-5718-1968-0226829-0, for the fraction-free idea); `kerDim m = D − rank([2G^z; G^+; G^-]|_{basis})`. `fuseR`/`cornerCountR` = Mathlib-free copies of `fuse`/`cornerCount` (`lean/Su2Plaq/Structure/Counts.lean`, read-only). Theorem `corner_kernel_dims : (List.range 81).all (fun m => invariant gz b ∧ invariant gp b ∧ invariant gm b ∧ kerDim m == cornerCountR (isQ m 0) (isQ m 1) (isQ m 2) (isQ m 3)) = true`, `b = cornerBasis m`, `isQ m e = ((m / 3^e) % 3 == 2)`. **W4** `corner_count_agree : ∀ a b c d : Bool, cornerCountR a b c d = cornerCount a b c d` (Bridge, imports `Su2Plaq.Rishon.Counts`).

**W3 — exact gate semantics of `build_UE` (P4).** Coefficient ring $\mathbb Z[i][z,z^{-1}]$, $z=e^{i\alpha/4}$, sparse `Lau` = sorted `(exponent, re, im)` and `Vec` = sorted `(basis index, Lau)` exactly as spinnet `Semantics.lean` (copy the prototype). Gates and Qiskit matrices: `x q`, `cx c t` (little-endian permutation), `p q a` $=P(a\alpha/4)=\mathrm{diag}(1,z^a)$ (Qiskit `PhaseGate(θ) = diag(1, e^{iθ})`; `build_UE` uses `p(−3α/4)` so $a=-3$). `gadget l = [.cx (4l) (4l+1), .p (4l+1) (-3), .cx (4l) (4l+1)]`. `innerCodes` = $\{a+16b+256c+4096d: a,b,c,d\in\text{sector}\}$; `nQ y` = number of links $l<4$ with `linkCode y l ∈ linkQ`; `ueTarget y = [(y, [(−3·nQ y, 1, 0)])]` $=z^{-3\#Q}|y\rangle=e^{-i\frac34\alpha\#Q}|y\rangle$. Theorems: `card_inner_codes : innerCodes.length = 1296`; `ue_gadget_sector : sector.all (fun s => runGates (gadget 0) [(s, one)] == [(s, [(if linkQ.contains s then -3 else 0, 1, 0)])]) = true` (every sector code is an eigenvector, phase $z^{-3}$ exactly on the quartet — the parity trick $n_{L_1}\oplus n_{L_2}=1\Leftrightarrow Q$ is *checked*, not assumed); `ue_gates_structure : ueGates = (List.range 4).flatMap gadget`; `ue_outer_gates_structure : ueOuterGates = (List.range 12).flatMap gadget`; `ue_exact_all_codes : innerCodes.all (fun y => runGates ueGates [(y, one)] == ueTarget y) = true`. `ueGates`/`ueOuterGates` are **rendered from the Qiskit circuits** `build_UE(1.0)` and `build_UE(1.0, with_outer=True, include_outer_electric=True)` between generated markers (never typed in); the locked test checks the literals verbatim and ties the Lean gate matrices to Qiskit `Operator`.

**O1 — certified outer electric row.** For `qc = build_UE(α, with_outer=True, include_outer_electric=True)` (48 qubits, no ancilla): partition the gates by link $\ell=q\,\mathrm{div}\,4$; any gate touching two links → not certifiable (`reason = "cross_link_gate"`); per link $V_\ell$ = exact $16\times16$ `Operator` of that link's sub-circuit (program order); target $T_\ell=\mathrm{diag}_{s\in\text{sector}}(e^{-i\frac34\alpha[s\in Q]})$; $\varphi_\ell$ = phase of $\sum_{s}\overline{(T_\ell)_{ss}}(V_\ell)_{ss}$ (phase 1 if the modulus is $<10^{-300}$); $\epsilon_\ell=\|V_\ell[:,\text{sector}]-e^{i\varphi_\ell}T_\ell\|_2$ (the $16\times6$ block: includes leak out of the sector codes). Because the circuit is $\bigotimes_\ell V_\ell$ on disjoint qubits, on every superposition of valid 48-bit codes
$$\Big\|\Big(\bigotimes_\ell V_\ell-e^{i\sum\varphi_\ell}\bigotimes_\ell T_\ell\Big)\Psi\Big\|\le\sum_{\ell=0}^{11}\epsilon_\ell=:\texttt{error\_bound}$$
(telescoping of a product of unitaries, the same inequality as the laptop's `prod_sub_prod_le`/`synth_bound`, METHODS §11); exhaustive over all $6^{12}$ valid codes and hence all 38 432 physical states. `certified = (no cross-link gate) ∧ (no ancilla register) ∧ error_bound ≤ tol_err`; method label `"outer_electric_gadgets"`. Measured: 5 ms, error 0.0 at $\alpha=0.37,0.91$; mutant $P(10^{-7})$ on an outer qubit → $1.0\times10^{-7}$.
