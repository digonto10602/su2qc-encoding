## Findings (none blocks B6)

- **F1 (defect against its own docstring): `compute=False` is ignored for encodings served by a registered `headline` hook.** `robust.headline` delegates to `info.headline(kind, root, refresh)` before looking at `compute`. `report.report_table` calls it with `compute=False` for "never computed here", so for spinnet and rishon the generic report path (`python -m su2plaq.compress.report --encoding spinnet`) rebuilds every program at 21 angle pairs when the track cache is stale and rewrites `results/compress/<enc>/robust.json`. Measured on a copy: 46.8 s, `robust.json` mtime changed. The cache of the real tree is stale right now (hash changed), so the CLI would do this and dirty a tracked file. The track modules' own `report_table` pass `headline=False`, so they are unaffected. Guess: the delegation branch needs `if not compute: return None` (or a cache-only call) as the generic branch has. No unit test covers it (the toy `report_table` test uses a non-hook encoding).
- **F2 (planner question, as announced): the generic rule changes the fuzzy_ub headline.** With the generic $\rho$ the fuzzy_ub headline is `r10-F1-010`, not the archive best `r12-F1-012`, and 34 of the pairwise orders among 41 entries flip. Research 005 §1 and the table in `prompts/008` (0 flips among 11 fuzzy_ub entries) assumed no $\rho$ effect. Cause verified above: Clifford offsets ($-\pi$, $-3\pi/2$) inside `rz` angles make the angle non-homogeneous-linear; they cost no extra T. All entries have the same $T_{\rm sum}=12688$, so $\rho$ and then depth (30902 vs 30908) decide. Not a code bug; the rule is open.
- **F3 (cosmetic): the spinnet round brief now carries the shared paragraph** (heading `## Headline rule`, generic wording) instead of the track paragraph `(track S)`; `spinnet.loop.HEADLINE_RULE_SECTION` still exists but the brief no longer uses it. The shared text states the same rule. Acceptance M4 and M6 tests pass.
