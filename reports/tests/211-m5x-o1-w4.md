## 4. Judgement of the builder-declared deviation (anchor vs sum-fit phase)
**Facts.** (i) Plan 202 section 1 writes $\varphi_\ell=\arg\sum_s\overline{(T_\ell)_{ss}}(V_\ell)_{ss}$ (sum fit). (ii) The same paragraph says "Measured ... mutant $P(10^{-7})$ on an outer qubit $\to1.0\times10^{-7}$", and the planner prototype `scratch/planner/proto_outer_row.py` anchors on `d[0]/abs(d[0])` (sector code 3, type A, target phase 1) - exactly what the builder implemented. (iii) The locked test asserts `error_bound >= 0.9e-7` for that mutant. (iv) For that mutant the true operator-norm error up to one global phase is $|e^{i\theta}-1|/2=5.0\times10^{-8}$ (3 of 6 codes get $e^{i\theta}$, 3 get 1), which is what the sum fit and the optimal phase both return.

**(a) Soundness - yes.** For any real $\varphi_\ell$, $\|(\bigotimes V_\ell-e^{i\sum\varphi_\ell}\bigotimes T_\ell)\Psi\|\le\sum_\ell\|V_\ell[:,\text{sector}]-e^{i\varphi_\ell}T_\ell\|$ by telescoping, because $\|V_\ell\|=1$, $\|T_\ell\|=1$ and the phases multiply into one global phase; the choice of $\varphi_\ell$ enters only through the target, never through the proof. Numerical check (`sound.py`, 80 trials, 3 links = $6^3$ codes, random Hermitian and phase-only perturbations $10^{-6}$ to $0.3$ of the true gadget): the exact $\|\bigotimes B_\ell-e^{i\sum\varphi}\bigotimes T_\ell\|_2\le\sum\epsilon_\ell$ held in 80/80 trials for each of the three phase choices (0 violations), and each bound is $\ge$ the numerically minimised error over a global phase (anchored: max bound/true minimum 2.25; sum: 2.06; opt: 1.98). The phase-degenerate case ($|z|<10^{-300}\to\varphi=0$) is still sound.

**(b) At least as strict as the sum fit - not provably, in practice almost always.** The anchored bound satisfies $\epsilon(\varphi_{anchor})\le2\,\epsilon_{opt}$ (triangle inequality; measured max anchored/opt $=1.99999999$), so it is never more than 2x pessimistic and never optimistic. It is not guaranteed to be $\ge$ the sum-fit bound: in 3 of the 78 non-trivial random trials the anchored bound was 0.4 % to 1.4 % smaller than the sum-fit one (min anchored/sum $=0.986$, max $1.85$); on all deterministic mutants above the anchored bound is $\ge$ sum $\ge$ opt. Both are valid; neither dominates. The optimal-phase bound is the tightest valid one (and would fail the locked $\ge0.9\times10^{-7}$ assertion just like the sum fit).

**(c) Which text is inconsistent - the plan prose, not the test.** The plan's formula for $\varphi_\ell$ (sum fit) contradicts the plan's own measured value ($1.0\times10^{-7}$), its prototype (anchor) and the locked threshold ($0.9\times10^{-7}$); the test and prototype agree with each other and with the shipped code. The builder's choice is a sound certificate (a) and the only one of the plausible phase rules that satisfies all locked assertions. Latent test-internal note: the test's own helper `_own_link_errors` uses the sum fit and is compared to `link_errors` to $10^{-14}$, which holds only because every unmutated link has error exactly 0 under any phase rule; if a later locked test fed a defective circuit to both, the two rules would disagree (anchored vs sum, factor up to 2). Recommendation for the planner (no action by tester): correct section 1 / METHODS-rishon R9 to the anchored rule or state that any phase is admissible and the anchor was chosen for the detection margin; the builder's R9 bullet already records this.
