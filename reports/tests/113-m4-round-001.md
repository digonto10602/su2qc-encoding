## Method

Target for a step: $V=U_B(\beta)\,U_E(\alpha)$ with $U_B=\exp(-i\beta H_B)$, $H_B$ = `su2plaq.exact.spinnet.h_magnetic_phys_6j` (route B, the M3 gauge), $U_E=\mathrm{diag}\,e^{-i\alpha H_E}$, `scipy.linalg.expm`. Circuit $C$ run by Aer on each of the 433 physical codes $y+256\,o$ (16 bits; ancillas from qubit 16). $M_{jk}=\langle y_j|C|y_k\rangle$ is the $433\times433$ block. Error $=\lVert M-e^{i\varphi}V\rVert_2$ with fitted global phase $\varphi$. "ancilla" = squared amplitude with any ancilla bit set; "leak" = squared amplitude on a data/outer code outside the 433; "outer changed" = squared amplitude where the 8 outer bits differ from the input. "max col residual" = largest per-input full residual including all of the above. Build is an in-process `exec` of the archived file (not the sandbox worker). Angle pairs $(\alpha,\beta)=(0.37,0.61),(0.91,0.23),(1.70,1.00)$.
